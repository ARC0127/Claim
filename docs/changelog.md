# 版本记录

## 0.3.0 · 2026-09-17 · internal

- 新增命令行启动器，可选择 Claude Code 或 Codex；支持 UTF-8 上下文导出和本地环境检查。
- 补充 Claude Code 个人/项目安装方式，不再以 Codex 作为唯一入口。
- 新增 Lean 与可选 Prove2Me 证明路线，以及独立的基础算术示例。
- 支持向用户指定的本地工具交接任务；不自动发现其他安装。
- 通读润色主页和文档，补充内容对应的中英文 README 与语言切换。
- 主案例采用经典实分析的量词与一致收敛问题，加入极限与求导迁移题；所有案例独立于研究项目。

## 0.2.0 · 2026-09-17 · internal

- 新增 S5a 义务反馈参考，对照主张诊断最影响结论的单个缺项。
- 新增内置主张检查与确认后归档，移除核心路由的外部研究 skill 硬依赖。
- 补充反例前提核对、未找到反例的条件化继续路径，以及高概率主张的证伪边界。
- 重做主页，加入原创案例、使用指南、教学来源和验证说明。
- 新增独立 UTF-8 验证、文件清单与安装比较、确定性打包和回归测试。
- 保留已有教学阶段、中文标题、实时检索、变量解释、渐进提示、版本回退和迁移规则。
