额外兼容检查：显式指定外部宿主验证器并采用 Python UTF-8 模式时通过。宿主验证器默认编码的缺陷未由本项目改写；Claim 自己的验证路径不再依赖它。

复核命令（Python 3.10+，不需第三方库）：

```bash
python -B tools/validate.py
python -B -m unittest discover -s tests -v
python -B tools/package.py --check
python -B tools/validate.py --skill /path/to/extracted/claim
python -B tools/validate.py --installed /path/to/installed/claim
```

Windows 原生对照可运行 `powershell.exe -NoProfile -File tests/check-windows-encoding.ps1`，用 `-SkillPath` 指定解压或安装目录。

打包用 `python -B tools/package.py --write`。它只从 manifest 的核心文件白名单构建当前版本 ZIP，并刷新核心文件与各历史 ZIP 的校验和，不改写历史 ZIP。相同 Python/zlib 环境下检查重建字节一致；不声称跨所有压缩库版本字节必然相同。

本验证器显式解码 UTF-8，不依赖系统默认编码或其他 skill 的验证器。它拒绝非法 UTF-8、异常替换字符、私用区字符、BOM 不匹配及固定中文模板缺失；并非所有可能的语义乱码都能由这些规则检出。
